# AI Workflow Lab

A growing collection of practical examples, scripts, and tools for modern AI contractor work. This repository showcases hands-on skills in Python, SQL, JavaScript, JSON, and workflow evaluation—built to support real-world projects across AI model testing, data processing, automation, and LLM reasoning.

## 🚀 Purpose
This repo serves as a technical portfolio demonstrating core capabilities used in high-paying AI project roles. Each module highlights practical, job-relevant tasks such as:
- AI workflow evaluation  
- Data cleaning and preprocessing  
- Prompt engineering patterns  
- Front-end logic testing  
- JSON/YAML configuration  
- Automation with Python  

## 🧩 Contents
- **/python-tools** – utility scripts, data processing, automation  
- **/sql-queries** – structured data tasks and examples  
- **/js-snippets** – front-end logic and evaluation samples  
- **/llm-eval** – prompt engineering, reasoning tests, JSON workflows  
- **/resources** – cheat sheets, templates, and reference guides  

## 📚 Skills Demonstrated
- Python (beginner–intermediate)

- HTML/CSS structure
- JSON/YAML formatting
- Git & GitHub workflow
- AI model evaluation techniques
- Prompt engineering
